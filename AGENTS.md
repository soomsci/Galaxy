# Project workflow

- User preference: after completing requested changes and relevant verification, deploy immediately to GitHub Pages without asking for deployment confirmation again, unless the user explicitly asks to keep the change local or defer deployment.
- Deploy by committing the task changes and pushing to `origin/master`. Preserve unrelated work; do not force-push. Check the `deploy-pages.yml` workflow and verify the published site at https://soomsci.github.io/Galaxy/ before reporting completion.
